API reference

Everything exported from doculens — one function, one class, four types.

readDoc() DocReader ExtractionOptions ExtractionResult DocChunk DocType
Function

readDoc(filePath, options?): Promise<ExtractionResult>

One-shot convenience wrapper around new DocReader().read(filePath, options). Use this for a single extraction; use DocReader directly when you want to reuse options across many files.

import { readDoc } from 'doculens';

const result = await readDoc('report.pdf');
console.log(result.content);
Class

DocReader

Holds a set of default ExtractionOptions that apply to every read() call, unless overridden per call.

new DocReader(defaultOptions?: ExtractionOptions)

reader.read(filePath: string, options?: ExtractionOptions): Promise<ExtractionResult>
import { DocReader } from 'doculens';

const reader = new DocReader({ allSheets: false });

await reader.read('a.xlsx');                       // first sheet only
await reader.read('b.xlsx', { allSheets: true }); // overridden for this call
Interface

ExtractionOptions

Passed to the DocReader constructor as defaults, and/or to .read() / readDoc() per call.

FieldTypeDescription
maxCharsnumberTruncate output across chunks. Default: unlimited
pageByPagebooleanPDF: extract one chunk per page. Default: false
allSheetsbooleanXLSX: include every sheet, not just the first. Default: true
listOnlybooleanZIP: list entries only, don't extract contents. Default: true
encodingBufferEncodingForce a text encoding instead of auto-detecting. Default: auto-detect
streamingbooleanForce streaming mode for text files. Default: true for files > 10 MB
chunkSizenumberStream chunk size, in bytes. Default: 1 MB
Interface

ExtractionResult

Returned by every read() / readDoc() call — always, even when the underlying parser hit a problem.

FieldTypeDescription
typeDocTypeDetected format — see DocType.
contentstringFull text, all chunks joined with "\n\n".
chunksDocChunk[]Per-page / per-sheet / per-slide / per-record pieces — see DocChunk.
charCountnumbercontent.length.
truncatedbooleantrue if maxChars cut the output short.
warningsstring[]Non-fatal issues — encoding fallback, a scanned/image-only PDF, a parser that choked on the file structure. Extraction never throws for these; it reports them here instead.
Interface

DocChunk

One piece of a document's content — a page, a sheet, a slide, a record.

FieldTypeDescription
indexnumberZero-based position within chunks.
contentstringThis chunk's text.
sourcestring?Human-readable label, e.g. "Page 3", "Sheet: Finance", "Slide 2", "Record 14".
