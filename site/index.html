Stop writing a new parser for every file type

doculens gives you a single read() call for PDF, Word, Excel, PowerPoint, CSV, JSON and more — automatic format detection, streaming for large files, and graceful fallback instead of thrown exceptions.

Usage
index.ts 
import { readDoc } from 'doculens';

const result = await readDoc('quarterly-report.pdf');

console.log(result.content);   // extracted text
console.log(result.chunks);    // per-page / per-sheet / per-slide chunks
console.log(result.warnings);  // non-fatal issues, never a thrown exception
One API. Every format.

Detection runs on magic bytes, not just the extension — a renamed file still resolves correctly.

.pdf .docx / .doc .xlsx / .xls .pptx / .ppt .csv / .tsv .json / .jsonl .txt / .md .html / .xml .rtf / .epub .zip
Built for real-world files

Not just the happy path — the parts that actually break in production.

🧭

Smart type detection

Extension map, then magic bytes, then ZIP-container refinement for DOCX/XLSX/PPTX/EPUB.

🛟

Never throws

Malformed or unusual files degrade to a warning in the result, not a crashed process.

🌊

Streams large files

Text files over 10 MB stream automatically instead of buffering into memory.

🧩

Chunked output

Per-page, per-sheet, per-slide, per-record — ready for search indexes or LLM context windows.

Also works from the terminal

Installing the package gives you a doculens binary.

terminal 
# extract and pretty-print
npx doculens report.pdf

# page-by-page, truncated at 50k characters
npx doculens large.pdf --page-by-page --max-chars 50000

# raw JSON output
npx doculens notes.docx --json
